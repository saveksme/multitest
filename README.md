# Multitest

Интерактивный bash-скрипт для диагностики и тестирования Linux-серверов. Объединяет популярные инструменты проверки в одном меню.

## Быстрый старт

**Запуск без установки:**

```bash
bash <(curl -sL https://raw.githubusercontent.com/saveksme/multitest/master/multitest.sh)
```

**Установка как команда `multitest`:**

```bash
curl -sL https://raw.githubusercontent.com/saveksme/multitest/master/multitest.sh -o /usr/local/bin/multitest && chmod +x /usr/local/bin/multitest && echo "Установлено! Запуск: multitest"
```

После установки скрипт доступен из любого места:

```bash
multitest
```

### Мультитест и сводка-картинка

При выборе **Мультитеста** открывается список тестов с отметками:

| Клавиша | Действие |
|---------|----------|
| `↑` `↓` (или `k` `j`) | перемещение по списку |
| `ПРОБЕЛ` | отметить / снять тест |
| `A` / `N` | отметить все / снять все |
| `F` | только быстрые (до минуты) |
| `ENTER` | запустить отмеченные |
| `Q` | выйти без запуска |

Буквы принимаются и в русской раскладке — по той же физической клавише (`Ф` вместо `A`, `Т` вместо
`N`, `А` вместо `F`, `Й` вместо `Q`), чтобы не переключать раскладку ради одной клавиши.

Рядом с каждым тестом — примерное время прогона и пометка, если под него придётся доставить пакет;
внизу — сколько всего отмечено, суммарное время и список пакетов к установке. Ставится **только то,
что нужно отмеченным тестам**: выбрали одну проверку блокировок — sysbench и iperf3 на сервер не
поедут. В терминале без ANSI (или при запуске через `wget -qO- … | bash`) остаётся ввод номеров
строкой: через пробел/запятую, диапазоны вида `4-7`, Enter — все.

Во время прогона каждый тест стартует автоматически через 5 секунд; `Ctrl+C` пропускает текущий,
`s` — пропуск, `q` — выход.

По завершении формируется **сводка-картинка** и заливается на файлообменник — в консоль выводится
прямая ссылка. На карточке:

- шапка: адреса (замаскированные), гео, дата и крупная дробь «выполнено / запущено» плюс счётчик
  пропусков и ошибок — имя хоста на картинку не выводится, оно у большинства VPS выдаёт панель
  или провайдера целиком;
- блок характеристик сервера (CPU, RAM, диск, ОС, ядро, virt, IPv4, IPv6, ASN, BBR/qdisc,
  uptime, load);
- по карточке на каждый тест со **всеми** распознанными метриками (чипы) и построчным списком
  сервисов — рядом с каждым сервисом его **логотип** (Netflix, Spotify, YouTube, ChatGPT и т.д.;
  логотипы Simple Icons встроены в скрипт);
- пропущенные и упавшие тесты — со своим статусом; невыбранные собраны одной строкой-сноской внизу.

**Двойной стек.** Адреса определяются порознь (`curl -4` / `-6`) — без этого на dual-stack сервере
в отчёт попадал только IPv6, а IPv4 не показывался вовсе. Гео считается по IPv4, если он есть:
у туннельных брокеров IPv6 нередко «прописан» в другой стране, и это отдельный факт, а не гео
сервера. IP Region разбирает обе колонки таблицы: к метрикам добавляются консенсус и совпадения
по IPv6 и счётчик **v4≠v6** — сколько сервисов видят разные страны по стекам, ради этого числа
двойной стек и проверяют. У сервиса, который отвечает по стекам по-разному, показываются оба
ответа (`NL · DE`). Если IPv6 на сервере нет, ничего из этого не появляется.

Оформление **черно-серое**, без цвета и градиентов: состояние читается словом и контрастом —
норма приглушена, «внимание» в рамке, ошибка инвертирована (светлая плашка, тёмный текст), чтобы
самое заметное пятно на карточке доставалось тому единственному, что требует реакции.

Шрифт — **IBM Plex Sans** (рисовался под технические интерфейсы, полная кириллица); скачивается
автоматически, запас — Roboto/Noto/DejaVu. Рендер: `rsvg-convert` (или ImageMagick) — ставится автоматически.

**Хостинг картинки.** Сводка заливается на **x0.at** (анонимно, работает с VPS, ссылка живёт
~100 дней). Если он недоступен — пробуются запасные (catbox, litterbox, uguu и т.д.).
Примечание: анонимная загрузка файлов на catbox с хостинг/VPS-адресов им блокируется
(HTTP 412 «Invalid uploader»), а uguu.se удаляет файлы через 3 часа — поэтому основной x0.at.

### Утилиты

| # | Название | Описание |
|---|----------|----------|
| 1 | BBR + Cake | Включение TCP BBR congestion control и Cake qdisc |
| 2 | Выключить IPv6 | Отключение IPv6 через sysctl |
| 3 | Beszel | Подключение ноды к своему хабу мониторинга |

#### Beszel

Ставится **только агент** — хаб (веб-интерфейс) должен уже где-то работать; на самой ноде держать
его смысла нет, он умрёт вместе с ней. В хабе (`Add System` или `Settings → Tokens`) показывают
готовую команду установки: скопируйте её целиком и вставьте в запрос. Команда **не выполняется** —
из неё вынимаются только адрес хаба, токен и публичный ключ. Можно ввести и по частям.

Что делается сверх официального инсталлятора:

- **Проверка вставленного.** Инсталлятор кладёт значения в systemd-юнит строками
  `Environment="TOKEN=…"` и ничего не экранирует: кавычка или перевод строки внутри значения
  дописали бы в юнит свою директиву, то есть выполнение произвольной команды от root. Поэтому
  адрес, токен и ключ проверяются по строгому формату, а комментарий у ключа отбрасывается.
- **Агент не слушает наружу.** Проверено на живом бинаре: агент поднимает SSH-сервер на `*:45876`
  даже в WebSocket-режиме, когда входящие подключения не нужны. Здесь он переводится на
  unix-сокет — публичного порта не появляется вовсе.
- **Юнит с токеном закрывается** до `600` (инсталлятор создаёт его с `644`). Если служба с такими
  правами не поднимется — права возвращаются, чтобы не оставить ноду без мониторинга.
- **Спрашивается про группу `docker`.** Инсталлятор добавляет в неё пользователя `beszel` ради
  статистики контейнеров, но членство в этой группе равносильно root — можно отказаться.
- По `http://` (не `https`) на внешний адрес — предупреждение и явное подтверждение: токен ушёл бы
  открытым текстом.

Токен универсальный: одним можно подключить несколько нод, но для **новых** регистраций он живёт
около часа. Уже подключённая нода работает дальше бессрочно.

## Зависимости

Скрипт автоматически установит недостающие пакеты:

- `curl`
- `wget`
- `sysbench`

Поддерживаемые пакетные менеджеры: `apt`, `dnf`, `yum`, `apk`, `pacman`.

## Требования

- Linux (Debian/Ubuntu, CentOS/RHEL, Fedora, Alpine, Arch)
- Права root (для установки пакетов и утилит)
- Bash 4+
